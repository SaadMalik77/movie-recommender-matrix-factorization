# Movie Recommender with Matrix Factorization: ALS vs. Truncated SVD

DS5020 Linear Algebra and Probability for Data Science, Fall 2026 (Dr. Fatema Nafa)

We predict missing movie ratings by approximating the user–movie rating matrix as
R ≈ UVᵀ, and compare two methods built from scratch in NumPy:
Alternating Least Squares (ALS) and truncated SVD.

## Getting the data

We use MovieLens 100K (100,000 ratings from 943 users on 1,682 movies).
The raw files are not stored in this repository. To download them:

1. Download `ml-100k.zip` from https://grouplens.org/datasets/movielens/100k/
2. Unzip it inside `data/`, so that the ratings file is at `data/ml-100k/u.data`

Or from the repository root:

```bash
curl -L -o data/ml-100k.zip https://files.grouplens.org/datasets/movielens/ml-100k.zip
unzip data/ml-100k.zip -d data/
```

## Running the code

```bash
python src/load_data.py     # load MovieLens, describe the data, save plots to figures/
python src/simulation.py    # simulation with known truth (checks the derivations)
```
